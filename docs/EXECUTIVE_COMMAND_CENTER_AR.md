# مركز قيادة الإدارة العليا — دليل القراءة

## الوصول
- المسار: `/Executive/CommandCenter`
- الصلاحية: `telecom.reports.mis`
- الأدوار: GM (TelecomManagement)، مدير منطقة، مدير فرع — كلٌ يرى نطاقه الهرمي فقط.

## شريط النطاق الموحّد
- **منطقة / فرع / تاريخ** — نفس الفلاتر تُطبَّق على كل التبويبات.
- GM: كل الفلاتر متاحة.
- مدير منطقة: مقفل على إقليمه (فرع اختياري ضمن الإقليم).
- مدير فرع: مقفل على فرعه (عرض فقط).

## التبويبات

### 1. نظرة سريعة (Scorecard)
8–10 بطاقات KPI: إيراد، ARPU، تسرب 30/60، عمليات، تذاكر، SLA، تنبيهات، متصلون الآن، أفضل/أضعف فرع.

### 2. الشبكة والتكامل
- نبض CBS/HLR من سجلات `BillingIntegrationLog` — **وسم Demo** (محاكاة، ليس ربطاً خارجياً).

### 3. MIS المالي
- تحليلات استراتيجية + `revenueByCategory` + تسرب 60 يوم + خريطة حرارة الفروع.
- مصدر الإيراد: دفتر المدفوعات المحلي (Huawei CBS demo path).

### 4. العمليات (read-only)
- ملخص مدفوعات، تفعيلات، عمليات معلقة، تذاكر متأخرة SLA.
- **لا** موافقات باك أوفيس — مراقبة فقط مع روابط drill-down.

### 5. أداء الموظفين
- جدول هرمي حسب النطاق مع `productivityScore` شفاف (ليس AI).
- نقرة على موظف → KPIs 7/30 يوم + timeline موحّد.

### 6. التنبيهات والتدقيق
- استثناءات إدارية + تدخلات المشرف + SignalR للتنبيهات الحرجة.
